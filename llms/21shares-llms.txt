# 21Shares

> 21Shares AG is a Swiss-headquartered issuer of physically backed cryptocurrency exchange-traded
> products (ETPs), founded in 2018 as Amun AG and part of the 21.co group. It runs the largest suite of
> crypto ETPs in the world, listed on regulated European exchanges. **21Shares publishes no public API,
> no developer portal and no SDKs.** The only machine-readable data it distributes is the FinDatEx
> European template family (EMT / EPT / EET) as XLSX files on its CDN.

Generated by API Evangelist on 2026-09-05 from a probe of 21Shares' public surface. This file is an
independent third-party index, not a document 21Shares publishes.

## What is machine-readable

- [European MiFID Template (EMT) V4.2](https://cdn.21shares.com/uploads/current-documents/products/emt/EMT.xlsx): FinDatEx target-market, cost and ex-ante/ex-post reporting data for the full ETP range, keyed on ISIN. Producer 21Shares AG, LEI 254900UWHMJRRODS3Z64, contact etp@21shares.com.
- [European PRIIPs Template (EPT)](https://cdn.21shares.com/uploads/product_documents/EPT/EPT.xlsx): FinDatEx PRIIPs cost and risk data exchange, including each product's KID publication date and web address.
- [European ESG Template (EET) V1.1.3](https://cdn.21shares.com/uploads/current-documents/products/eet/EET.xlsx): FinDatEx SFDR / MiFID sustainability-preferences / IDD data.
- [Insights RSS feed](https://www.21shares.com/en-eu/insights/rss.xml): research notes, monthly flow reports and market commentary.

## What is NOT available

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, gRPC or WSDL contract on any 21Shares host.
- No developer portal, API reference, sandbox, API key signup or SDK. The published sitemap carries 8,267 URLs and contains no developer page.
- No MCP server, A2A agent card, llms.txt, /apis.json or any served /.well-known/ document.
- `https://data.21shares.com` is an AWS API Gateway on 21Shares' own domain, but it answers 403 Forbidden to every anonymous request on every path and method, and is documented nowhere.
